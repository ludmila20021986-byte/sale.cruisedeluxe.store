## Если сайт "пропал" или показывает не то — как проверить
1. Открыть https://cruise-sale-site.vercel.app в браузере — если открывается
   и видно распродажу, сайт жив, дело в чём-то другом (домен/DNS/кэш).
2. Если не открывается — зайти в панель Vercel (ссылка выше), раздел
   **Deployments**, посмотреть последний деплой и его статус.

## Как восстановить/переопубликовать сайт с нуля
Если проект на Vercel случайно удалили или сломали — восстановление за 5 минут:

1. Скачать код с GitHub (если нет локальной копии):
   ```
   git clone https://github.com/ludmila20021986-byte/sale.cruisedeluxe.store
   cd sale.cruisedeluxe.store
   ```
2. Установить Vercel CLI, если его нет:
   ```
   npm install -g vercel
   ```
3. Войти в свой аккаунт Vercel:
   ```
   vercel login
   ```
4. Задеплоить в продакшн:
   ```
   vercel --prod
   ```
   При первом запуске CLI спросит, к какому проекту привязать — можно создать
   новый или выбрать существующий `cruise-sale-site`.

## Как редактировать сайт дальше (без Claude)
Проект подключён к GitHub, поэтому автоматический деплой работает так:
1. Отредактировать `index.html` (текст, цены, товары).
2. Сохранить изменения в git и отправить на GitHub:
   ```
   git add index.html
   git commit -m "обновление цен/товаров"
   git push
   ```
3. Vercel сам увидит новый коммit в `main` и через 1-2 минуты выкатит
   обновлённую версию на https://cruise-sale-site.vercel.app и
   https://sale.cruisedeluxe.store.

Если git connect по какой-то причине отвяжется — можно просто зайти в панель
Vercel → Settings → Git и подключить репозиторий заново, указав
`ludmila20021986-byte/sale.cruisedeluxe.store`.

## Подключение поддомена sale.cruisedeluxe.store (если ещё не сделано)
DNS домена `cruisedeluxe.store` управляется в **Cloudflare**
(https://dash.cloudflare.com). Нужно добавить запись:
- Type: `CNAME`
- Name: `sale`
- Target: `cname.vercel-dns.com`
- Proxy status: **DNS only** (серое облако, не оранжевое)

После этого в Vercel: Settings → Domains → добавить `sale.cruisedeluxe.store`
к проекту `cruise-sale-site` (или это сделает Claude/CLI-командой
`vercel domains add sale.cruisedeluxe.store cruise-sale-site`, если DNS уже
настроен — до настройки DNS команда не сработает, это защита самого Vercel).

## Важно про основной магазин
Апекс-домен `cruisedeluxe.store` (без `sale.`) — это ОТДЕЛЬНЫЙ сайт, реальный
магазин на платформе **InSales**. Он никак не связан с этим Vercel-проектом.
Трогать DNS-записи апекс-домена (A-запись, MX и т.д.) для этой задачи не нужно
и опасно — можно сломать основной магазин.
